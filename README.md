<div align="center">

**Browser-Based Medical Imaging Viewer**

`REACT` `VITE` `CORNERSTONE3D` `DICOM`

I'm currently building a browser-based medical imaging workstation focused on learning how diagnostic images can be loaded, rendered, navigated, and interacted with inside a modern web application.

### Current exploration

- DICOM image handling
- Medical image visualization
- Cornerstone3D
- Imaging viewport architecture
- Clinical imaging workflows
- Measurement and interaction tools
- De-identified/public imaging datasets
- Future AI-assisted imaging concepts

**Repository:**  
[→ Medical Imaging Viewer](https://github.com/JewelsCoode)

> This project is the centerpiece of the direction I'm exploring:

# 🩺 `CLINICAL × SOFTWARE`

The workflow I'm interested in looks something like:

```text
PATIENT
   │
   ▼
CLINICIAN
   │
   ▼
IMAGING SYSTEM
   │
   ▼
MEDICAL IMAGE
   │
   ▼
DICOM / DATA
   │
   ▼
SOFTWARE
   │
   ▼
VISUALIZATION
   │
   ▼
CLINICAL INTERPRETATION
```

Understanding the clinical workflow can change how software should be designed.

Understanding software can change what is possible within that workflow.

That's the intersection I'm exploring.
